# Security Policy

| Version | Supported          |
| ------- | ------------------ |

## Reporting a Vulnerability

We take the security of BoundaryBench and its dependencies seriously. If you discover a security vulnerability in this project:

1. **Do not create a public GitHub issue.**
2. Report the vulnerability privately via [GitHub Security Advisories](https://github.com/maintainer/BoundaryBench/security/advisories) or contact the project maintainers directly:
   **[SECURITY_CONTACT_EMAIL - Please configure security contact email]**

Please provide:
- A clear description of the vulnerability.
- Steps to reproduce or a minimal proof of concept.
- Affected components or versions.

We will acknowledge receipt within 48 hours and work with you to triage and resolve the issue responsibly.

## Scope & Authorized Use Notice

- **Educational & Defensive Testing Only**: BoundaryBench contains intentionally vulnerable API endpoints designed exclusively as local educational test fixtures.
- **Localhost Bound**: All demonstrations are restricted to local mock data and `localhost` targets.
- **No External Scanning**: BoundaryBench is not designed for and explicitly rejects scanning unauthorized third-party networks or systems.
